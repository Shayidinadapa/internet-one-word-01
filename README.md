One word for the whole internet: **feral**.

## Why "feral"?

The internet is not a garden — it is a wild animal that escaped its cage a long time ago. Nobody owns it, nobody can fully tame it, and every corner of it — the memes, the arguments, the 3 a.m. rabbit holes — grows on its own, untamed and unmoderated. "Feral" is funny because it pictures the entire internet as a stray creature hissing at you from under the porch, and it is true because that is exactly how it behaves. It is not the obvious word everyone reaches for, and it lands in a single beat: five letters, instantly readable.

## How it works

`main.ts` writes the word `feral` to `/output/entry.txt`, after validating the bounty gate: 1–30 characters, not only whitespace, exactly one word.

## Run it

Requires Node 22.18 or later (TypeScript runs directly):

```sh
node main.ts
cat /output/entry.txt
# feral
```
